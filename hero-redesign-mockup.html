    Fixes

  • Removed eyebrow — headline + tagline say it all
  • A-frame reduced to 35% opacity — watermark, not focal point
  • Star ✦ removed, rotation reduced to 3deg
  • Breathing room: 20px after h1, 28px before buttons
  • Single CTA — "Start a Project" only
  • 5 elements in viewport (down from 7)

    • What Changed

    1Removed eyebrow — "Independent design. Distinctive possibilities." was redundant with the tagline below it. The h1 + tagline already communicate the value proposition.
    2A-frame → watermark — Opacity reduced to 35%, star ✦ removed, rotation reduced from 8deg to 3deg, border removed. It now reads as a subtle brand mark, not a competing focal point.
    3More breathing room — 20px gap after h1 (was 14px), 28px before buttons (was 21px), 48px grid gap (was 37px). Text elements now feel spacious.
    4Single CTA — Removed "View Work" button. One clear action ("Start a Project") is stronger than two competing ones.
    5More vertical padding — 32px top / 48px bottom (was 20px / 40px). The hero now feels intentional rather than cramped.
